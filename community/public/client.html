CLIENT API / 02

下载无需登录，
贡献只需一个 Key。

官方 OCR 客户端已经接入词库同步。普通用户无需配置；希望共享本地翻译时，在控制面板生成 Key 并填入客户端即可。

1

选择游戏

客户端会自动下载通用词库以及所选游戏的最新词库包。

2

启用共享

在客户端设置中开启“共享本地词典”，粘贴控制面板生成的 API Key。

3

后台提交

搜索确认的专名与模型生成的菜单短标签进入上传队列；对白和描述文本始终留在本地。

PUBLIC ENDPOINT

词库下载

GET /api/v1/dictionaries/{gameId}

无需身份验证，返回每个词条当前评分最高的译文。

CONTRIBUTION ENDPOINT

社区上传

Authorization: Bearer nst_live_••••
POST /api/v1/contributions
