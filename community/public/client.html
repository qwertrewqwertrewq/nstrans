CLIENT API / 02

下载无需登录，
登录即可参与共建。

官方客户端自动同步所选游戏词库。使用词库无需登录；参与共享时，在客户端注册、登录或通过 GitHub 授权，凭据会自动保存，无需手动复制 Key。

1

选择游戏

客户端会自动下载通用词库以及所选游戏的最新词库包。

2

登录并选择共享

在设置向导或密钥管理中登录，再主动开启词库共享。登录本身不会自动开启上传，也可用于访问“wiki镜像”。

3

后台提交

搜索确认的专名与模型生成的菜单短标签进入上传队列；对白和描述文本始终留在本地。

PUBLIC ENDPOINT

词库下载

GET /api/v1/dictionaries/{gameId}

无需身份验证，返回每个词条当前评分最高的译文。

社区上传

Authorization: Bearer nst_live_••••
