词库数据 API

以下接口均使用客户端密钥认证。score 是统一的可信度评分：赞 +1、踩 -1，API 新增或修改 +1。

API v1

认证请求头Authorization: Bearer nst_live_••••

获取游戏列表

curl https://nstrans.221129.xyz/api/v1/games \
  -H "Authorization: Bearer nst_live_••••"

按游戏 ID 批量获取词库

curl https://nstrans.221129.xyz/api/v1/dictionaries/batch \
  -X POST \
  -H "Authorization: Bearer nst_live_••••" \
  -H "Content-Type: application/json" \
  -d '{"gameIds":["general","zelda-totk"]}'

每条记录包含 termId、translationId、source、target、kind、score 与 updatedAt；单次最多 20 个游戏、10000 条译文。

覆盖单条数据 评分 +1

curl https://nstrans.221129.xyz/api/v1/translations/123 \
  -X PATCH \
  -H "Authorization: Bearer nst_live_••••" \
  -H "Content-Type: application/json" \
  -d '{"source":"ハイラル平原","target":"海拉鲁平原"}'

批量覆盖数据 每条评分 +1

curl https://nstrans.221129.xyz/api/v1/translations/batch \
  -X PATCH \
  -H "Authorization: Bearer nst_live_••••" \
  -H "Content-Type: application/json" \
  -d '{"items":[
    {"translationId":123,"source":"ハイラル平原","target":"海拉鲁平原"},
    {"translationId":124,"target":"监视堡垒"}
  ]}'

source 或 target 可只提交其中一项；实际发生覆盖才加分。批量请求每次最多 100 条，冲突项会在 rejected 中单独返回。

新增单条数据 评分 +1

curl https://nstrans.221129.xyz/api/v1/translations \
  -X POST \
  -H "Authorization: Bearer nst_live_••••" \
  -H "Content-Type: application/json" \
  -d '{"gameId":"zelda-totk","kind":"term","source":"プルア","target":"普尔亚"}'

批量新增数据 每条评分 +1

curl https://nstrans.221129.xyz/api/v1/translations/batch \
  -X POST \
  -H "Authorization: Bearer nst_live_••••" \
  -H "Content-Type: application/json" \
  -d '{"items":[
    {"gameId":"zelda-totk","kind":"term","source":"プルア","target":"普尔亚"},
    {"gameId":"general","kind":"phrase","source":"セーブ","target":"保存"}
  ]}'

完全相同的原文与译文不会重复新增，也不会重复加分。
