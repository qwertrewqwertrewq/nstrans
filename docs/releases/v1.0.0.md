# NSTrans 1.0.0

NSTrans 首个正式 Release：实时游戏 OCR 翻译、可选本地或远程翻译、社区词库与电视字幕输出。

## 主要功能

- macOS、Windows、iPadOS、Android 各提供 WithLlama 与 RemoteOnly 两种安装包；另提供 Android TV 字幕客户端。
- WithLlama 支持本地 TranslateGemma 与 NLLB 机器翻译，模型另行下载；RemoteOnly 使用远程 LLM 或在线机器翻译，不包含本地模型运行时。
- 支持采集卡预览和音频输出、框选识别、暂停翻译、字幕覆盖及电视字幕传输；硬件能力取决于平台及设备。
- 词库模式优先利用所选游戏词库与缓存，再进行专名搜索和学习；也可直接将 OCR 文本交给翻译模型。通用库自动加载，常见片假名排除词用于减少无效搜索。
- 新增“wiki镜像”：通过社区 Worker 访问免费 Wikimedia API，需要已登录社区或配置社区 Key；原有免费 Wiki 直连方式继续保留。
- 客户端支持注册、登录及浏览器 GitHub 授权，凭据自动保存。登录提前至设置向导第二步，可跳过；共享上传仍需用户主动开启。

## 界面与可靠性

- 日夜主题、单页模块切换与多屏幕比例适配。
- 修复向导本地引擎选择不同步、下载失败后状态误报、取消登录后异步凭据写入问题。
- 更新提示使用模态窗口，强制更新无法通过 Esc 绕过；“稍后提醒”不再永久忽略该版本。
- 社区页面改善错误反馈、移动导航与词库切换竞争问题，接入说明更新为自动登录流程。
- 本轮生产前端构建及 109 项自动化测试通过；布局检查覆盖 6 种屏幕尺寸、2 种主题、9 个控制模块。此结果不代表所有平台硬件均已实机验证。

## 使用与隐私说明

- 仅使用公开词库无需登录；共享的是符合筛选条件的专名、单词和短标签，不应上传完整对白或描述段落。
- 专名检索使用公开渠道。启用远程翻译会发送待翻译文字；启用远程视觉识别会发送对应区域截图，请按需启用。
- 发行包不包含游戏画面、剧情文本或翻译模型权重。公开资料及模型仍遵循各自授权。

## 已知限制

- macOS 曾在 M4 / 16GB RAM 上运行良好；iPad 曾在 M2 / 8GB RAM 使用 IQ4_XS 测试，IPA 需要用户自行签名。
- Android 主要仅在骁龙 750G / 8GB / Android 11 验证启动，未充分验证实际翻译性能；APK 当前使用调试签名。
- Android TV 应用内 HDMI 声音尚不支持。若设备无法授予悬浮窗权限，需要主机外接音源。
- 在线翻译与搜索受网络和供应商服务变化影响；远程模型需要自行配置可用 API Key。
- GitHub 正式 Release 标记不等同于 Apple 公证、App Store 或 Google Play 发行签名。
