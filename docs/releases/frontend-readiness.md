# 正式发布前：前端检查

## 本轮改进

- Wiki 镜像接入社区 Key 验证；设置向导第二步登录，登录与共享上传分别选择。
- 本地翻译选项立即同步核心引擎；模型下载失败后不再误报“下载进行中”并放行下一步。
- 账号登录支持回车、取消及离开模块时终止请求，避免延迟响应写入凭据。
- 更新提示使用模态对话框，强制更新拦截 Esc；“稍后提醒”仅在本次会话内忽略，通知内容更新后重新提示。
- 社区接口故障不再全部重定向 OAuth；词库快速切换时忽略过期请求。
- 社区移动导航支持 Esc 收起和展开状态声明；撤销 Key 的异常反馈；接入说明更新为客户端登录流程。
- 补充键盘焦点与矮屏更新窗口样式。

## 已完成验证

- TypeScript / Vite 生产构建通过。
- Vitest 109 项测试通过（包括 Wiki 镜像与强制更新回归）。
- 客户端 6 种视口 × 日夜主题 × 9 个模块：无整页横向或纵向溢出。
- 社区 390、1024、1440 像素宽度下的首页、接入、工作方式、下载及 6 个控制台页面：使用模拟 API 数据检查，无横向溢出或 JavaScript 异常。
- 实际浏览器截图检查客户端日间名词搜索与社区移动端版本通知页。

## 发布前仍须完成

- 本轮尚未重新打包或进行四平台原生设备验收；模拟 API 检查不代替真实登录及上传联调。
- 工作区已有 Android 生成项目文件删除，未擅自恢复或纳入本轮改动；发布前确认生成流程可重建。
- 1.0.0 发布流程已改为先创建草稿，四平台与 TV 构建全部完成后公开为 Latest 正式版；不覆盖旧版本。
- 生产社区页面尚未部署本轮 UI 改动。
