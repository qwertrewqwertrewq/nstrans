# NSTrans 0.1.4 Alpha

本版本修复社区游戏目录在新安装客户端中的同步问题，并包含 0.1.3 的设置向导、界面、采集卡音频和社区游戏管理更新。

## 修复

- 客户端启动时会匿名同步社区中全部已开放游戏，不再要求先填写社区 API Key。
- 修复 iPadOS 等新设备只显示内置“塞尔达传说：王国之泪”的问题。
- 浏览和选择现有游戏保持匿名；只有新建社区游戏、上传词条和共享本地学习成果时才要求客户端 API Key。
- 修复社区控制台创建游戏已经返回 `201 Created`，页面仍因异步表单引用失效而显示错误的问题。

## 当前社区目录

客户端会从 `https://nstrans.221129.xyz/api/v1/games` 下载已开放游戏，并将目录缓存到本机。网络暂时不可用时继续使用最近一次成功同步的目录；“通用游戏”仍作为内部必加载词库，不出现在适配游戏选择列表中。

## 构建与许可

Release 继续提供 macOS、Windows、Android、iPadOS 的 `WithLlama` 与 `RemoteOnly` 版本，以及 Android TV 字幕客户端。macOS 未公证、iPadOS 需要自行签名，Android 使用调试签名。
