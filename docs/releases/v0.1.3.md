# NSTrans 0.1.3 Alpha

本版本集中改进首次配置、采集卡音频、单页控制界面和社区游戏目录，并继续提供 `WithLlama` 与 `RemoteOnly` 两类构建。Alpha 版本用于兼容性与效果验证；macOS 未公证、iPadOS 需要自行签名，Android 使用调试签名。

## 初始设置与界面

- 新安装默认进入六步设置向导，依次配置主题、核心翻译方式、专有名词学习、社区共享、适配词库和重启提示。
- `WithLlama` 构建可选择本机 NLLB-600M 或 TranslateGemma；Windows 可进一步选择 CUDA、Vulkan 或 CPU。`RemoteOnly` 不显示本地模型选项。
- 控制界面调整为固定单页布局，右侧模块按需切换；日间主题重新设计，并加入全局明暗主题开关。
- 输入源、采集卡音频、预览控制、暂停翻译、上下文重置和处理延迟集中在预览下方。

## 采集与电视字幕

- 增加采集卡 HDMI 音频监听及 macOS、iPadOS、Android 麦克风权限说明；关闭后重新启用会再次触发设备与权限检查。
- 电视字幕输出整合到模块导航，继续支持文本与透明图片图层两种传输方式。
- Android TV 字幕客户端仍随 Release 一并构建；部分电视固件无法在应用内播放 HDMI 声音，需要主机外接音源。

## 社区游戏目录

- 社区游戏不再进入人工审核队列。中文名必填，日文名与 HTTPS 封面地址可选，创建后立即开放。
- 管理员可以在控制台编辑或删除游戏；删除游戏会级联删除其词条、候选译文和评分。
- 设置向导新建游戏必须提供社区客户端 API Key，并直接写入远程目录，不再创建仅存在于本机的适配项。
- 客户端同步远程游戏目录并缓存列表；游戏词库、通用词库和共享贡献的原有隐私过滤规则保持不变。

## 构建与隐私

- GitHub Release 同时构建 macOS、Windows、Android、iPadOS 的 `WithLlama` 与 `RemoteOnly` 版本，以及 Android TV 字幕客户端。
- NSTrans 不记录视频画面、截图或完整游戏对白。远程模型只接收用户所启用功能所需的文本或局部截图；社区服务器只接受经过长度、结构和标点规则过滤的专有名词、单词与短标签。
- TranslateGemma 受 Gemma Terms of Use 约束；NLLB-200 600M 及其兼容 ONNX 转换采用 CC BY-NC 4.0，不包含在本项目 Apache-2.0 许可中。
