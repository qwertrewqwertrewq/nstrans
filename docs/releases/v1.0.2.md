# NSTrans 1.0.2

## 接入社区中转模型

- 客户端可在「密钥管理」中选择「社区中转模型」，使用社区登录凭据及账号额度，无需自行填写上游模型 API Key。
- 翻译、名词搜索、远程视觉识别分别由社区服务器分配模型，客户端无需选择具体型号；仍可使用自有 API Key 或原有本地翻译方式。
- 管理员可配置 Google Gemini、阿里百炼、DeepSeek 的模型与密钥，按用途设置多个模型及优先顺序；上游请求失败时依次切换备用模型。
- 社区管理面板支持额度分配、批量调整、额度清空与使用记录查看；新注册用户默认获得 30 点，实际扣点以社区当前配置为准。
- 社区网页重构为 Vue 3 + Element Plus，采用独立页面及路由，保留词库、评分、账号、密钥与管理功能。

## 安装与使用

- macOS、Windows、Android、iPadOS 继续提供 WithLlama 与 RemoteOnly；使用社区中转可选择 RemoteOnly，无需下载本地大模型。
- iPadOS IPA 仍需自行签名，Android APK 仍使用调试签名；Android TV 作为独立字幕客户端一并提供。
- 使用远程模型会向上游发送待处理文字及按需截取的局部图像，请勿提交敏感内容。免费上游服务的数据使用政策以对应平台为准。
